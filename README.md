# StoryShaper

> Kids today *watch* stories on endless autoplay; they rarely get to *shape* one.

아이가 말로 이야기에 끼어들면 그림과 전개가 바로 바뀌는 인터랙티브 동화책.
[Meta Global AI Developer Hackathon](https://cerebralvalley.ai/e/meta-ai-developer-hackathon) (2026.10.26 ~ 11.04) 출품작입니다.

- 트랙: Indie Developer
- 주제: Build for Your World

- [킥오프 정리 (PDF)](docs/kickoff-summary.pdf): 킥오프 라이브스트림 내용, 규칙, 심사 기준, 일정
