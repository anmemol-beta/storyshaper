프로젝트에 Meta 모델을 포함하는 것이 필수다. 모델 선택은 실제 문제·입출력·비용·응답 속도를 확인한 뒤 결정한다. 공지의 모델 목록만으로 세부 API 지원 범위나 사용 가능 리전을 단정하지 않는다.

## Meta Model API — 1인당 $150

- 대상: 선발된 참가자. 개인·팀원·스타트업 참가자 모두 각자 신청한다.
- **대리 신청 불가.** 팀 대표 한 사람의 신청으로 4명 전원의 지급이 완료되지 않는다.
- 신청: [Meta Global AI Hackathon: Model API Credit Claims](https://docs.google.com/forms/d/e/1FAIpQLScam78z7tHsNYibiFyJQVFzEgr0coyBTiY568SxxNbsPa3jiw/viewform).
- 마감: 미국 동부 11/04 21:00 = **한국 11/05(목) 11:00**.
- 신청 후 크레딧을 여러 차례 나누어 지급하므로 **신청 완료 ≠ 지급 완료**다.
- 각자 Billing에서 무료 크레딧이 반영되었는지 확인한다.
- 크레딧 이용·API 호출에는 계정에 신용카드 등록이 필요하다.
- 유효 결제수단 등록 시 일시적인 사전 승인 금액이 표시될 수 있으며 가이드는 영업일 며칠 내 자동 해제를 안내한다.
- Billing에서 Spend Limit **알림(notification)**을 설정할 수 있다. 공지만으로 하드 한도·자동 결제 차단을 보장할 수 없다.
- 공식 규정은 $150 크레딧을 10일 개발 창에 유효한 것으로 설명한다. 계정별 정확한 만료 시각과 별도 Credit Terms는 신청 전 확인한다.

**4인 팀 적용:** 전원이 적격 승인 참가자이고 각각 지급받으면 명목상 `4 × $150 = $600`이다. 이는 **각 개인 계정의 크레딧 합계 계산**이며 팀 공용 $600 잔액, 계정 간 양도·통합·공유 허용을 뜻하지 않는다. 현재 4명의 신청·지급 상태는 미확인이다.

### 개인별 진행 순서

1. 본인의 참가 승인과 계정을 확인한다.
2. 신청서·Credit Terms를 확인하고 직접 신청한다.
3. 필요한 결제수단 등록을 본인이 진행한다.
4. Billing에서 $150 반영과 사용 조건·알림을 확인한다.
5. 선택한 모델을 최소 입력으로 실제 호출해 응답과 사용량을 확인한다.
6. 팀 표에는 신청·지급·실호출 여부만 기록하고 비밀 키는 남기지 않는다.
