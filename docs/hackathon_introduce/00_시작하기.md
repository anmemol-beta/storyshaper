# Meta 글로벌 AI 개발자 해커톤 — 참가 문서 모음

> 확인 기준: 2026-10-26, 한국 시간(KST). 제공받은 한국어 번역문을 보존하고, Cerebral Valley의 메인 공지·참가자 가이드·공식 규정을 직접 대조해 정리했다. 공식 일정과 팀 내부 권장 계획은 구분한다.

## 가장 먼저 볼 내용

- **프로젝트 제출 마감: 2026-11-05(목) 11:00 KST** = 11월 4일(수) 21:00 미국 동부시간(EST).
- **개막식: 2026-10-27(화) 01:00 KST** = 10월 26일(월) 12:00 미국 동부시간(EDT). 상세 가이드의 ET를 기준으로 변환했다. 메인 공지의 EST 표기 혼용은 [출처·확인 사항](07_출처와_확인필요사항.md) 참고.
- **현재 상태: 사용자 Discord 참여 완료, 4인 팀 구성 완료.** 팀 정원 4명을 채웠다.
- 참가 트랙·프로젝트 주제·팀 대표·역할·크레딧 신청 여부는 아직 확정 정보가 없다.
- 필수 준비물은 **Meta 모델을 활용한 실제 작동 프로젝트, 공개 코드 저장소, 3분 데모 영상, 제출 페이지의 팀원 전원 명단**이다.
- 대표 1명이 팀 프로젝트 1건을 제출한다. 늦은 제출은 심사하지 않는다.

## 읽는 법

1. `01`과 `02`로 아이디어·트랙·평가 기준을 맞춘다.
2. `03`의 한국 시간 일정을 공유한다. **11월 1일 미국 서머타임 종료 전후 시차가 다르다.**
3. `04`에서 담당자와 완료 상태를 관리한다. 미확인 항목은 완료로 표시하지 않았다.
4. `05`에서 각자 크레딧을 신청하고 실제 API 호출을 확인한다.
5. `06`을 기준으로 제출물을 준비하고 `08`의 팀 합의·권리 조건을 전원이 확인한다.

## 정보의 성격

- **공식 확인:** 공지·가이드·규정에 명시된 대회 조건.
- **사용자 확인:** Discord 참여 및 4인 팀 구성 완료.
- **권장:** 팀 역할·내부 마감·작업 순서·데모 구성 등 실행 제안. 공식 의무나 확정된 팀 결정이 아니다.
- **확인 필요:** 페이지 간 모순, 상세 시간이 없는 일정, 현재 확인하지 못한 개인별 상태.
