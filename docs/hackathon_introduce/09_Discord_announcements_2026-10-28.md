## Agents 101 실습 준비 안내

9번 공지에 명시된 내용이다. 프로젝트 개발의 필수 의무가 아니라 **워크숍 실습 준비사항**이다.

1. Muse Code를 내려받는다.
2. 자신의 API 키로 Muse Code에 로그인한다.
3. [meta-models/legal-agent-workshop](https://github.com/meta-models/legal-agent-workshop) 저장소를 준비한다.
4. 아래 명령으로 실습 디렉터리와 환경 파일을 준비하고 `.env`에 `MODEL_API_KEY`를 넣는다.

```sh
git clone https://github.com/meta-models/legal-agent-workshop.git
cd legal-agent-workshop/agent
cp .env.example .env
```

- 공지의 예상 토큰 사용 비용은 **약 $7**이다. 고정 가격이나 실제 청구 결과가 아니다.
- 권장 환경: **macOS 또는 Linux, git, Python 3.9 이상**.
- Windows는 WSL이 필요할 수 있으나 **미검증**이라고 공지했다.
- 이번 기록 작업에서는 설치·저장소 복제·API 호출을 실행하지 않았다.
