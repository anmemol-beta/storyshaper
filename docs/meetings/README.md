# StoryShaper 회의록

회의의 결정·논의·미정 사항을 구분해 보관한다. 모든 시각은 한국 시간(Asia/Seoul)이다. 자동 받아쓰기의 인명 오류는 사용자 확인을 우선하며, 원문 발언을 공식 대회 조건이나 구현 완료로 취급하지 않는다.

## 회의 목록

| 날짜·노트 시작 시각 | 회의 | 주요 내용 |
| --- | --- | --- |
| 2026-10-28 20:09 | [개발 방향·기능 논의](2026-10-28-2009-product-and-development.md) | 창의성·교훈 유지, 부모 목소리·배역 음성, 에이전트 구분, 개발·데모 목표 |
| 2026-10-28 20:49 | [역할 확정·중간 통합 계획](2026-10-28-2049-roles-and-integration.md) | 현준: 음성 / 지호: 동화 에이전트 / 수찬: image to video·UI/UX·앱, 금요일 중간 점검 |

두 노트는 같은 날 이어서 진행한 회의다. 1차 회의의 미정 역할·일정 논의는 2차 회의와 사용자의 최종 확인을 함께 읽는다.

## 확정된 개발 담당

| 담당자 | 담당 기능 |
| --- | --- |
| 현준님 | 음성 개발 |
| 지호님 | 동화 에이전트 개발 |
| 수찬님 | image to video, UI/UX, 앱 개발 |

근거: 2026-10-28 2차 회의 원문과 같은 날 사용자가 직접 확인한 역할. 개발 담당 3명에 대한 기록이며, 기존 참가 팀의 전체 인원이나 제출 명단 변경을 뜻하지 않는다.

## 후속 작업

- [ ] 각 담당자가 기능 개발을 진행하고 카카오톡으로 중간 결과를 공유한다.
- [ ] **10월 30일(금)** 중간 결과물을 합쳐 보고 다음 작업을 조정한다. 회의 시각은 미정이다.
- [ ] 녹음·인식·에이전트·이미지/영상·낭독의 입출력 규격과 폴더·브랜치 경계를 합의한다.
- [ ] 주말 개발 목표와 월요일 데모 준비 계획은 금요일 통합 결과에 맞춰 조정한다. 데모 콘티·촬영 담당자의 정확한 이름과 최종 일정을 확인한다.
