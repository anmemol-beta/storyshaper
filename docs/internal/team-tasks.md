1. [ ] 첫 편 장면 명세: 고정 사건과 결말, 변경 항목, 예상 답, 거절 문구, 기본 대체 장면.
2. [ ] 작은 서버: API 키 보호, 세션과 장면 상태, 생성 요청 제한, 기본 오류 처리. 정적 HTML에서 직접 호출하면 키가 노출된다.
