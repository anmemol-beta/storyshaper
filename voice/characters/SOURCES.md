# Stock character voices

Reference clips for the default character voices. Each clip is only used as a Chatterbox voice prompt.

| File | Role | Source | Speaker / utterance | Median pitch |
|---|---|---|---|---|
| `wolf_libritts_1188.wav` | Wolf | LibriTTS-R `test.clean` | speaker 1188, `1188_133604_000012_000003` | 98 Hz |
| `pig_libritts_237.wav` | Pigs | LibriTTS-R `test.clean` | speaker 237, `237_134493_000006_000004` | 230 Hz |

LibriTTS-R (Koizumi et al., 2023) is released under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
It is a restored version of LibriTTS (Zen et al., 2019), which is built from public-domain LibriVox audiobooks.
Clips were taken from the Hugging Face copy `mythicinfinity/libritts_r` and are unmodified.
